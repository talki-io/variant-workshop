# ADR 0002 · 历史爆款样本永久缺失，不建离线校准层

- **状态**：Accepted
- **日期**：2026-07-03（提炼归档于 2026-07-10）
- **来源**：交接文档 `HANDOFF-FIXME.md` §3 / `HANDOFF-BACKEND.md` §9.7（已删除，见 git 历史）

## 背景

`docs/architecture.md` §0.3 把 40–50 条历史爆款定义为「离线真值锚」，由它离线提炼出模式库、多调性语感指纹、风格参考向量、去 AI 味判别器 few-shot。这是全系统质量的地基。

**样本始终未到位，且需求方已确认不补。**

## 决策

**不建离线校准层。** 生成走「通用调性版」+ few-shot 最小可用形态。

因此以下指标是**近似占位，不是待修的 bug**：

| 字段 | 真实含义 |
| --- | --- |
| `score` / `aiScore` | 模型自评，非客观评分 |
| `styleDistance` | 由 `aiScore` 派生的近似值，**不是真实向量距离** |
| `diversity` | 维度组合的近似估计 |
| `style_vectors` 表 | 建表未灌数据，仅验证 `CREATE EXTENSION vector` 生效 |

`bandit` 奖励与权重同样未实现——它需要真实采用埋点积累到一定量才有意义（`telemetry_event` 表已在收集 `adopt` / `generate` 信号）。

## 后果

- **不要试图「修准」这些指标。** 真值依赖校准层，校准层依赖样本。
- 若产品要更准，唯一路径是「拿到样本 → 建校准层」，那是一个独立立项。
- 看到「把 styleDistance 算对」「让评分更客观」这类需求，先回来读这份 ADR。
